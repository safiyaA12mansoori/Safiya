Safiya Dental Clinic ERP — Bootstrap Frontend
============================================

Fully working frontend using:
- HTML
- CSS
- JavaScript
- Bootstrap 5 (CDN)

HOW TO OPEN
-----------
1. Unzip this folder.
2. Open index.html in Chrome / Edge / Firefox
   (internet needed once for Bootstrap + fonts CDN).

OR serve locally:
  npx --yes serve .
  Then open the URL shown (usually http://localhost:3000).

FEATURES
--------
- Patients, Dentists, Medicines, Prescriptions
- Appointments (conflict detection)
- Treatments, Billing
- Data saved in browser localStorage
- Demo data included (Reset demo data button on Overview)
