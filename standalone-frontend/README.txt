Safiya Dental Clinic — Animated Bootstrap Frontend
==================================================

HTML + CSS + JavaScript + Bootstrap 5

WHAT CHANGED
------------
- Animated UI (cards, tabs, stats, patient history)
- Dentists module removed
- Medicines module removed
- Click any patient to see previous appointments, prescriptions, and bills

HOW TO OPEN
-----------
1. Unzip
2. Open index.html in Chrome / Edge / Firefox
   (internet needed once for Bootstrap CDN)
