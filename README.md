# Safiya Mansoori — Portfolio

Personal portfolio for **Safiya Mansoori**: Operations Manager at Atenar Tech, founder of AromaLuxe, and a multi-skilled professional in data analytics, digital marketing, and web.

## Run locally

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000).

## Structure

- `index.html` — page content
- `css/styles.css` — layout and visual design
- `js/main.js` — nav, scroll header, reveal motion
- `assets/` — hero and section imagery
